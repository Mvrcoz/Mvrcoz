          How this works

          • What leaves your device: only when you press “Check for breaches”, the first 5 characters of a scrambled fingerprint (SHA-1 hash) of your password go to Have I Been Pwned. Nothing else is ever sent. No accounts, no tracking, no ads.
          • Password strength is an estimate. A password this tool rates well can still be guessed if it is built from personal details.
          • “Not found in known breaches” means the password is not on that list. It does not prove the password is safe.
          • The link checker reads how a link is written. It cannot see what is on the site, so “No red flags found” never means “safe”.
